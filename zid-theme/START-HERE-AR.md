## خطواتك أنت (لازم حسابك)

### أ) حسابات
1. سجّل متجر على https://web.zid.sa/register باسم **خير الجوار**
2. سجّل/ادخل شريك على https://partner.zid.sa (نفس الإيميل أو إيميل المطوّر)
3. ثبّت الأدوات محليًا:
```bash
npm install -g @zidsa/vitrin-cli
vitrin login
vitrin new khair-aljaar-zid
```

### ب) الثيم
1. انسخ محتوى `zid-theme/assets` وملفات الـ jinja للهوية داخل الثيم اللي Vitrin أنشأه
2. أو اربط المجلد الحالي:
```bash
cd zid-theme
vitrin new khair-aljaar-zid --from-existing .
```
3. معاينة:
```bash
vitrin preview
```
4. ارفع للشريك ثم فعّل على المتجر (باقة احترافية أو خدمة ثيم مخصص):
```bash
vitrin push
```
أو ارفع ZIP من لوحة المتجر → سوق الثيمات → ثيم مخصص

### ج) المحتوى على لوحة زد

#### ⚠️ الصفحات الداخلية (مهم — بدونها الروابط تفشل)
1. ادخل https://web.zid.sa → **المتجر الإلكتروني → الصفحات**
2. أنشئ **5 صفحات** بالـ slug **بالضبط** (حروف إنجليزية صغيرة):

| slug | عنوان EN | عنوان AR |
|------|----------|----------|
| `about` | About Khair Aljaar | من نحن — خير الجوار |
| `partners` | Our Partners | شركاؤنا |
| `quality` | Quality | الجودة |
| `logistics` | Logistics | اللوجستيات |
| `contact` | Contact | اتصل بنا |

3. انسخ النصوص من `PAGES-CONTENT-AR-EN.md` (عربي + إنجليزي لكل صفحة)
4. الرابط على زد يكون: `/pages/about` (جمع pages — **مش** `/page/about`)
5. بعد رفع ثيم **1.5.1** فعّل النسخة الجديدة من: **المظهر → ثيمات المتجر**

#### منتجات وتصنيفات
1. أضف التصنيفات: موالح / تمور / فواكه / خضروات / مجمدات
2. ارفع المنتجات من `products-import.csv` (أو يدويًا) + صور `assets/images/products/`
3. الأصل في كل منتج: **Jeddah, Saudi Arabia** فقط (بدون مصر)
4. فعّل عربي + إنجليزي من إعدادات المتجر
5. بعد الدفع: دومين + زد باي + شحن

### د) الدفع والنشر
1. رقِّ الباقة للاحترافية **أو** اشترِ «ثيم مخصص»
2. اربط الدومين
3. اختبر سلة ودفع
4. انشر
